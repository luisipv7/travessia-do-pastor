# Travessia do Pastor — jogo educativo

Jogo de raciocínio lógico feito com **HTML, CSS e JavaScript puro**, pensado para aulas de Informática.

## Objetivo

Levar o pastor, o cão pastor, o lobo e a ovelha da margem esquerda para a margem direita sem violar as regras.

## Regras

- O pastor sempre pilota o barco.
- O barco pode levar no máximo um animal por travessia.
- O lobo não pode ficar sozinho com a ovelha sem o pastor.
- O cão pastor e o lobo não podem ficar sozinhos juntos sem o pastor.
- O pastor pode atravessar sozinho.
- Também é permitido trazer um animal de volta.

## Modo desafio

Esta versão foi preparada para os alunos resolverem **por tentativa e erro**.

- Não existe botão “Ver solução”.
- Não existe botão de dica.
- O jogo não informa a quantidade mínima de movimentos.
- O aluno pode usar **Desfazer** e **Reiniciar** para testar estratégias diferentes.

## Como executar

Abra `index.html` em qualquer navegador moderno. Não é necessário servidor nem internet.

## Conceitos de programação trabalhados

- HTML semântico
- CSS responsivo
- Eventos do DOM
- Objetos e estados
- Condicionais (`if`)
- Funções
- Validação de regras
- Histórico de movimentos
- `localStorage` para guardar o recorde
- Raciocínio algorítmico e resolução de problemas

## Sugestão para a aula

Antes de mostrar o código, peça que cada aluno registre em papel a sequência de tentativas. Depois, compare a estratégia usada no jogo com as condições implementadas no JavaScript.
